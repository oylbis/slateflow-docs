# Version history

## 2.0.0 — Current release

Full feature set described in this guide:

- One-click project setup ("Setup Storyboard Session").
- Frame-accurate navigation between shots and drawing scenes (Tab,
  Ctrl+←/→, Alt+←/→).
- Bidirectional duration sync between strips and drawing scenes, with trim
  or push-neighbors resize modes.
- Shared drawing-scene detection and protection (warning marker, locked
  editing until resolved).
- Live selected-shot overlay (name, duration).
- Automatic sound sync from the edit into each drawing scene.
- On-image metadata overlay (shot name, frame number, duration), each
  independently toggleable.
- Batch shot creation and renaming, unused-scene cleanup, timeline
  rendering split by topmost-visible-strip segments.

storyFlow builds on the official **Storypencil** add-on (Blender
Foundation), extending it into a complete storyboard/animatic workflow.
