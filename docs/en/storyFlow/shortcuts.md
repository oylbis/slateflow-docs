# Shortcuts reference

| Action | Shortcut | Where |
|---|---|---|
| Jump into the selected shot's drawing | **Tab** | VSE |
| Back to the edit | **Tab** | Dope Sheet / Graph Editor / 3D View |
| Previous/next shot | **Ctrl+←** / **Ctrl+→** | VSE |
| Previous/next drawing scene | **Alt+←** / **Alt+→** | Dope Sheet / Graph Editor / 3D View |
| Previous/next animation key (then shot, once keys run out) | **Ctrl+Alt+←** / **Ctrl+Alt+→** | Dope Sheet / Graph Editor / 3D View |
| Trim the neighboring shot when resizing | Drag a strip handle (default) | VSE |
| Push following/preceding shots when resizing | **Ctrl** + drag a strip handle | VSE |
| Open the resize options popup (add/remove exact frames) | Double-click a strip handle | VSE |

!!! info "No custom shortcuts to configure"
    Unlike dopesheetFlow's 3D-viewport scrubbing, storyFlow's shortcuts are
    fixed — there's no preferences panel for rebinding them at this time.
