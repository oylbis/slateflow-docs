# Preferences & shortcuts

**Edit > Preferences > Add-ons > sequencerFlow** lists every tool below
with its current shortcut. Click a shortcut field, press the key combo
you want, done — **live conflict detection** warns you before you
overwrite an existing Blender shortcut. Changes apply immediately, no
restart needed.

| Action | Default shortcut |
|---|---|
| Cut | **C** |
| Join | **J** |
| Swap Left / Swap Right | **Ctrl+Alt+←** / **Ctrl+Alt+→** |
| Slip | **S** |
| Connect / Disconnect | **Ctrl+G** / **Alt+G** |
| Select Left / Right | **Ctrl+Shift+←** / **Ctrl+Shift+→** |
| Select Above / Below | **Ctrl+Shift+↑** / **Ctrl+Shift+↓** |
| Select Channel | **Alt+A** |
| Selection Sets (open panel) | **Ctrl+A** |
| Insert (PRO) | **,** (comma) |
| Source Viewer Set In / Set Out (PRO) | **I** / **O** |

!!! info "Not in this list"
    Navigate next/previous strip, Isolate, Frame range, Follow Playhead,
    Auto Range, Batch Rename and Export Segments are toolbar/panel buttons
    only — they don't have a keyboard shortcut to remap. Ctrl+click to add
    a curve keyframe (PRO) and dragging a zone guide boundary are mouse
    gestures, not configurable key bindings either — see
    [Features](features.md) for both.

!!! info "Dual Monitor I/O (PRO)"
    While a Clip Editor area is acting as the Dual Monitor, **I** / **O**
    set its own in/out points — a separate, fixed shortcut (not listed
    above, and not remappable) that only does anything in that context.
