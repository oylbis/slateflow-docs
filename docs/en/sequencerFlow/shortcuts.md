# Preferences & shortcuts

**Edit > Preferences > Add-ons > sequencerFlow** lists every toolbar tool
with its current shortcut. Click a shortcut field, press the key combo you
want, done. Changes apply immediately, no restart needed.

!!! info "PRO-only shortcuts"
    The Source Viewer's Insert, Set In and Set Out entries only appear in
    the PRO edition — see [LITE and PRO](index.md#lite-and-pro).
