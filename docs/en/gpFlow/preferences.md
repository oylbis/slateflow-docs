# Preferences & shortcuts

**Edit > Preferences > Add-ons > gpFlow** lists every tool below with its
current shortcut. Click a shortcut field, press the key combo you want,
done — **live conflict detection** warns you before you overwrite an
existing Blender shortcut. Changes apply immediately, no restart needed.

| Tool | Default shortcut |
|---|---|
| Draw | **D** |
| Erase | **E** |
| Fill | **Alt+F** |
| Select | **S** |
| Select & Transform | **Alt+T** |
| Sculpt | **Alt+S** |
| Lengthen/Shorten | **Alt+L** |
| Deform | **Ctrl+T** |
| Deform (inherit current selection) | **Ctrl+Alt+T** |
| Canvas rotation | **Alt+R** |

!!! info "Not in this list"
    Flip Horizontal/Vertical and the three animation shortcuts (empty key,
    duplicate previous, shift keyframes) are toolbar buttons only — they
    don't have a keyboard shortcut to remap.
