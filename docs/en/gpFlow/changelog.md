# Version history

Current version: **2.3.0**.

## Since the first release

- Removed Smart Fill (superseded by the native Fill tool), added Deform's
  inherited-selection mode, and redesigned the default keyboard
  shortcuts.
- Draw, Erase, Fill and Sculpt no longer shadow Blender's own native
  right-click menus.
- Dropped Grease Pencil v2 compatibility entirely — gpFlow now targets
  GPv3 only (Blender 5.2+).
- Removed the unused Object-mode toolbar button.
- Fixed a dangling Lattice modifier that could appear when Deform's mode
  switch raced a native transform.
- Shortcut editing now uses Blender's own native keymap editor
  (Preferences > Keymap) instead of a custom panel.

## Roadmap

Addon consolidation and fixing any bugs that come up.

Feedback and suggestions are welcome — see [Support](index.md#support).
