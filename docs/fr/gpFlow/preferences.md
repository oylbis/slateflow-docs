# Préférences & raccourcis

**Edit > Preferences > Add-ons > gpFlow** liste chaque outil ci-dessous
avec son raccourci actuel. Cliquez sur un champ de raccourci, appuyez sur
la combinaison voulue, c'est fait — la **détection de conflit en direct**
prévient avant d'écraser un raccourci Blender existant. Les changements
s'appliquent immédiatement, sans redémarrage.

| Outil | Raccourci par défaut |
|---|---|
| Draw | **D** |
| Erase | **E** |
| Fill | **Alt+F** |
| Select | **S** |
| Select & Transform | **Alt+T** |
| Sculpt | **Alt+S** |
| Lengthen/Shorten | **Alt+L** |
| Deform | **Ctrl+T** |
| Deform (hériter la sélection actuelle) | **Ctrl+Alt+T** |
| Rotation du canevas | **Alt+R** |

!!! info "Absents de cette liste"
    Flip Horizontal/Vertical et les trois raccourcis d'animation (clé
    vide, dupliquer la précédente, décaler les clés) sont uniquement des
    boutons de toolbar — pas de raccourci clavier à reconfigurer.
