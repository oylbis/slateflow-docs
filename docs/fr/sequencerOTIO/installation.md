# Installation

1. Téléchargez le fichier `sequencerOTIO-<version>.zip` depuis votre
   source d'achat.
2. Glissez-déposez le `.zip` n'importe où dans la fenêtre de Blender — ou,
   depuis **Edit > Preferences > Get Extensions** (**Add-ons** sur
   certaines versions), utilisez le menu ▾ > **Install from Disk...** et
   sélectionnez le fichier.

Réinstaller un `.zip` plus récent remplace proprement la version
précédente — pas de doublon, rien à retirer manuellement.

Nécessite **Blender 5.2 ou plus récent**.

!!! info "La dépendance opentimelineio s'installe toute seule"
    Aucune manipulation nécessaire dans la plupart des cas — voir
    [Configuration](configuration.md) pour le détail et la marche à suivre
    sur une plateforme non couverte.
