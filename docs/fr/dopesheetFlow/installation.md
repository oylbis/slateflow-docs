# Installation

1. Téléchargez le fichier `dopesheetFlow-<version>.zip` depuis votre source
   d'achat.
2. Glissez-déposez le `.zip` n'importe où dans la fenêtre de Blender — ou,
   depuis **Edit > Preferences > Get Extensions** (**Add-ons** sur
   certaines versions), utilisez le menu ▾ > **Install from Disk...** et
   sélectionnez le fichier.

Réinstaller un `.zip` plus récent remplace proprement la version
précédente — pas de doublon, rien à retirer manuellement.

Nécessite **Blender 5.2 ou plus récent** (Grease Pencil v3).

!!! warning "Le bouton n'apparaît pas après l'installation ?"
    Sur un profil Blender qui n'a jamais eu l'addon installé, le bouton
    d'en-tête peut occasionnellement ne pas apparaître immédiatement après
    l'installation. Désactivez puis réactivez l'addon une fois (dans
    *Preferences > Get Extensions*, décochez puis recochez dopesheetFlow) —
    aucune réinstallation nécessaire.
