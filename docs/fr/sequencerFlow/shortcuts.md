# Préférences & raccourcis

**Edit > Preferences > Add-ons > sequencerFlow** liste chaque outil de la
toolbar avec son raccourci actuel. Cliquez sur un champ de raccourci,
appuyez sur la combinaison voulue, c'est fait. Les changements s'appliquent
immédiatement, sans redémarrage.

!!! info "Raccourcis réservés à la version PRO"
    Les entrées Insert, Set In et Set Out du Source Viewer n'apparaissent
    que dans l'édition PRO — voir [LITE et PRO](index.md#lite-et-pro).
