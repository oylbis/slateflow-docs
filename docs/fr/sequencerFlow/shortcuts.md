# Préférences & raccourcis

**Edit > Preferences > Add-ons > sequencerFlow** liste chaque outil
ci-dessous avec son raccourci actuel. Cliquez sur un champ de raccourci,
appuyez sur la combinaison voulue, c'est fait — la **détection de conflit
en direct** prévient avant d'écraser un raccourci Blender existant. Les
changements s'appliquent immédiatement, sans redémarrage.

| Action | Raccourci par défaut |
|---|---|
| Cut | **C** |
| Join | **J** |
| Swap Left / Swap Right | **Ctrl+Alt+←** / **Ctrl+Alt+→** |
| Slip | **S** |
| Connect / Disconnect | **Ctrl+G** / **Alt+G** |
| Select Left / Right | **Ctrl+Shift+←** / **Ctrl+Shift+→** |
| Select Above / Below | **Ctrl+Shift+↑** / **Ctrl+Shift+↓** |
| Select Channel | **Alt+A** |
| Selection Sets (ouvrir le panneau) | **Ctrl+A** |
| Insert (PRO) | **,** (virgule) |
| Source Viewer Set In / Set Out (PRO) | **I** / **O** |

!!! info "Absents de cette liste"
    Navigate next/previous strip, Isolate, Frame range, Follow Playhead,
    Auto Range, Batch Rename et Export Segments sont uniquement des
    boutons de toolbar/panneau — pas de raccourci clavier à reconfigurer.
    Ctrl+clic pour ajouter une clé sur une courbe (PRO) et le glisser d'une
    limite de guide de zone sont des gestes souris, pas des raccourcis
    clavier configurables non plus — voir
    [Fonctionnalités](features.md) pour les deux.

!!! info "I/O du Dual Monitor (PRO)"
    Tant qu'une zone Clip Editor joue le rôle de Dual Monitor, **I** / **O**
    y posent ses propres points in/out — un raccourci séparé et fixe (absent
    de la liste ci-dessus, non reconfigurable) qui n'agit que dans ce
    contexte.
