# Référence des raccourcis

| Action | Raccourci | Où |
|---|---|---|
| Entrer dans le dessin du plan sélectionné | **Tab** | VSE |
| Revenir au montage | **Tab** | Dope Sheet / Graph Editor / vue 3D |
| Plan précédent/suivant | **Ctrl+←** / **Ctrl+→** | VSE |
| Scène de dessin précédente/suivante | **Alt+←** / **Alt+→** | Dope Sheet / Graph Editor / vue 3D |
| Clé d'animation précédente/suivante (puis plan, une fois les clés épuisées) | **Ctrl+Alt+←** / **Ctrl+Alt+→** | Dope Sheet / Graph Editor / vue 3D |
| Rogner le plan voisin en redimensionnant | Glisser une poignée de strip (par défaut) | VSE |
| Pousser les plans suivants/précédents en redimensionnant | **Ctrl** + glisser une poignée de strip | VSE |
| Ouvrir le popup d'options de redimensionnement (ajouter/retirer des frames précises) | Double-clic sur une poignée de strip | VSE |

!!! info "Pas de raccourcis personnalisables"
    Contrairement au scrubbing 3D de dopesheetFlow, les raccourcis de
    storyFlow sont fixes — pas de panneau de préférences pour les
    réassigner pour l'instant.
